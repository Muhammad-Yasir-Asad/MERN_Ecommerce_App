# MERN E-Commerce Application

A full-stack e-commerce project organized around the **MongoDB, Express.js, React, and Node.js (MERN)** ecosystem.

## 🎯 Overview
This repository is intended to bring together a storefront frontend and server-side application logic. Review the current source code and configuration files for the implemented shopping, account, and product workflows.

## 🛠️ Technology
- MongoDB — document database
- Express.js — Node.js web framework
- React — user interface
- Node.js — JavaScript runtime

> Verify the actual dependencies and available features in the project manifests before deploying.

## 🚀 Getting Started
1. Clone the repository:
   `git clone https://github.com/Muhammad-Yasir-Asad/MERN_Ecommerce_App.git`
2. Open the project directory and inspect the available client/server folders.
3. Install dependencies in each directory containing a `package.json`:
   `npm install`
4. Configure the required environment variables using a local `.env` file. Never commit secrets.
5. Run the scripts defined in each `package.json` (for example, `npm run dev` only if that script exists).

## 🔐 Security Notes
Keep database credentials, JWT secrets, API keys, and other sensitive values out of version control. Use a local database or a properly secured hosted instance.
